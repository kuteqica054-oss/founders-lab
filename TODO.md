# Что нужно заполнить

На сайте каждое незаполненное место видно как жёлтая плашка **TODO**. Найти все места в коде: `npm run todo`.

## 1. Бренд и домен — `site.config.mjs`
- [ ] `BRAND_NAME`: подтвердить название (сейчас «Founders Lab», по аккаунту x.com/LAB_FOUNDERS)
- [ ] `url` или переменная окружения `SITE_URL`: боевой домен

## 2. Контакты — `site.config.mjs → contact`
- [ ] `email`
- [ ] `phone`: в американском формате, например (617) 555-0123
- [ ] `location.street`, `location.postalCode`: улица и ZIP мастерской (город уже указан: Boston, MA, USA)
- [ ] `hours`: часы работы
- [ ] `whatsapp`: по желанию; пока поле пустое, кнопка WhatsApp на сайте не показывается
- [x] `social.x`: https://x.com/LAB_FOUNDERS
- [ ] `social.instagram`, `social.linkedin`

## 3. Юрлицо — `site.config.mjs → legal`
- [ ] `entity`: название юрлица, например «Founders Lab LLC»
- [ ] `privacyEmail`: адрес для запросов по приватности (если не указать, берётся `contact.email`)
- [ ] `venue`: подсудность, например «the state and federal courts located in Suffolk County, Massachusetts»
- [ ] `updated`: дата последней редакции юридических текстов

## 4. Форма — `site.config.mjs → form`
- [ ] выбрать `provider`: `netlify` или `formspree`; для Formspree указать `formspreeId`
- [ ] Netlify: включить Form detection и уведомления на e-mail
- [ ] `budgetRanges`: диапазоны бюджета, например `{ value: 'under-5k', label: 'Under $5,000' }` (по желанию; без них будет текстовое поле)
